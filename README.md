# pfd-okdp-uns

`https://w3id.org/pfd-okdp/uns/`.

| Fichier | Contenu | Espace d'URI |
|---|---|---|

| `uns_referentiels.ttl` | référentiels SKOS, dont CPV 2008 | `https://w3id.org/pfd-okdp/uns/ref/` |
| `uns_decp_shacl.ttl` | formes SHACL du cas DECP | `https://w3id.org/pfd-okdp/uns/def#` |

Source : kit PFD-OKDP, `app/nifi-opale/ontologie/`.
